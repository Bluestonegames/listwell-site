Questions, answered

Before you get started

A few things to know about the Listwell concept.

Who is Listwell Landlord Hub for?

It is designed for UK landlords who want to organise property, tenant, rent, compliance, maintenance and administrative records in one workspace.

Can I pay monthly or annually?

The proposed plans include monthly and annual options. Actual billing periods, prices, taxes and plan entitlements need to be configured and verified before launch.

Can I pay by card or Direct Debit?

The planned checkout will use Stripe for secure payment processing. Card payments and eligible UK Bacs Direct Debit subscriptions will be offered only after the Stripe account, payment methods, webhook handling and subscription backend are configured.

Will my information be saved?

This preview does not create an account or save registration details to a server. Persistent storage, authentication, access controls and backups must be implemented before real data is entered.

Can I use tenant referencing?

A Lets Safe integration is planned. It requires a secure server-side connection, configured API credentials, user consent and testing before it can be used for real applicants.
